# Каталог космических миссий

Программа выводит список космических миссий и позволяет искать миссии по направлению.

## Возможности

- Вывод полного списка космических миссий
- Поиск миссий по направлению
- Сообщение, если миссии не найдены

## Структура проекта

| Файл | Описание |
|------|----------|
| `main.py` | Точка входа, запуск программы |
| `missions.py` | Функции вывода и поиска миссий |
| `README.md` | Описание проекта |

## Как запустить

1. Убедитесь, что установлен Python 3.x
2. Откройте папку `space_missions`
3. Запустите программу: `python main.py`
4. Следуйте подсказкам на экране.
